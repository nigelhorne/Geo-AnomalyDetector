   17: Geo::AnomalyDetector - Detect anomalies in geospatial coordinate datasets

   19: =head1 SYNOPSIS
   20: 
   21: This module analyzes latitude and longitude data points to identify anomalies based on their distance from the mean location.
   22: 
   23:   use Geo::AnomalyDetector;
   24: 
   25:   my $detector = Geo::AnomalyDetector->new(threshold => 3);
   26:   my $coords = [ [37.7749, -122.4194], [40.7128, -74.0060], [35.6895, 139.6917] ];
   27:   my $anomalies = $detector->detect_anomalies($coords);
   28:   print 'Anomalies: ', join ', ', map { ($_->[0], $_->[1]) } @{$anomalies};
   29: 
   30: Each co-ordinate can be either a two element array of [latitude, longitude] or an object that has
   31: C<latitude> and C<longitude> methods.
